# EndFlow 安全与授权边界

BCrypt12存储密码；会话30分钟、HttpOnly/SameSiteStrict；HTTPS环境启用Secure。登录失败8次限制账号5分钟。CSRF保护写接口，CSP、nosniff和frame-deny在Nginx设置。已停用账户及密码变化即时使接口失效，角色权限从数据库重新读取。

所有业务接口检查权限和范围：ALL全部部门，DEPARTMENT本部门，SELF本部门本人参与。执行仍检查指派。复核与编制、采购独立，最后全范围管理员保护避免锁死管理入口。版本和UUID用于避免重复并发记录，不替代审批人的真实审核责任。

JPQL固定且参数绑定；实体类型来自代码，客户端不能提供查询表达式。输入限长度、数量、日期、成本精度；十亿个数量上限。业务无文件上传，不实现外部来源链接抓取，导出只包含业务数据。源码发布检查秘密格式、原始品牌哈希、图像存在与许可一致，不等于专业渗透测试。

通知与凭证输入应使用去敏编号及组织受控位置，不能填写Token、密码、个人资料或客户秘密。原始凭证由组织独立保管。系统不自动识别或打码敏感输入，团队必须规范访问、备份、留存期限和删除权限。
