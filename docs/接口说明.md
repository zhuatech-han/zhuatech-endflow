# EndFlow HTTP接口

前缀/api。先GET /auth/csrf取header和token，再POST /auth/login提交username/password；登录刷新CSRF。写请求带指定CSRF头，会话Cookie由浏览器管理。不提供Token接口。

| 方法 | 路径 | 作用 |
| --- | --- | --- |
| GET | /auth/me、/options | 当前账号及范围内目录 |
| POST | /auth/logout、/auth/password | 退出及本人密码修改 |
| GET | /workbench、/dashboard、/audit | 本人待办、范围内统计和操作审计 |
| GET | /cases | search/status/page/size/sort(newest/deadline/code) |
| POST/PUT | /cases、/cases/{id} | 新建/更新草稿 |
| GET/DELETE | /cases/{id} | 详情/删除从未提交草稿，删除传version查询参数 |
| POST/PUT/DELETE | /cases/{id}/lines[/{line}] | 草稿用途快照维护，删除传version |
| POST | /cases/{id}/commands/{action} | submit/approve/return/order/receive/implement/close/cancel |
| POST | /cases/{id}/receipts/{receipt}/reverse | 指定独立复核员冲正 |
| GET | /cases/{id}/report.json | 原始业务JSON下载，no-store |
| GET/POST/PUT/DELETE | /admin/{type}[/{id}] | users/roles/departments/menus/permissions/dictionaries/settings |

创建/更新/命令输入包括requestKey(UUID)。修改带当前record.version。UUID绑定账号、路线及完整输入；完全相同的重试不重复写入，改变内容返回IDEMPOTENCY_CONFLICT。管理目录操作依赖唯一约束，不提供UUID幂等承诺。

命令共同输入note实际证据至少10字。order附reference、date(今日)、promisedDate；receive附唯一reference、date(订单日至今日)、quantity正整数；implement附reference实际实施凭证。冲正至少填note。所有数量拒绝小数。通知unitPrice至多4位小数，budget至多2位，负数被拒绝。

详情返回record、calculation、received、overdue、lines、receipts、events。列表返回items(通知摘要)、total/page/size。服务端返回401未认证、403权限或范围、400输入错误、409旧版本/状态/幂等冲突、404不存在。错误JSON只含code，不泄露内部异常。请求载荷样例由scripts/smoke.py提供，不含默认真实凭证。
