# EndFlow 使用手册

## 管理员准备

生成本机配置并启动后，以 admin 及 .env 中初始密码登录。先建部门，再按需求编制员、采购执行员、独立复核员岗位创建账号。四类默认岗位均可编辑；管理员限全范围，最后一个可用全范围管理员不可删除或降权。复核员须与编制员、采购员独立，同一人在具备权限时可兼任编制与采购。

## 记录原始通知

在“停产通知”新建记录，一个记录对应一个制造商料号。填制造商原始通知编号或受控链接、通知日期、末次订购和交货日期、所属部门、指定岗位。通知日期不能晚于今日，订购期限不早于通知，交货期限不早于订购。编号和部门创建后不能改变。系统不自动打开来源链接或检查内容真实性。

添加每个受影响产品用途，按实际核对的月需求、支持月数和售后保留需求登记。库存与在途必须先独立分配到用途，不能在不同用途或通知重复计入；供给分配由实际库存系统控制。系统只计算本通知中的快照。

选择末次采购、替代切换或产品退役。末次采购填写包装倍数、最小数量、单价、数量和预算；替代需写不同的候选料及验证报告，替代与退役采购数量必须为零。决策依据应解释数据来源、风险和超建议量的理由。

## 提交和独立复核

编制员提交后，需求和决策冻结。指定复核员根据受控原始文件复核，可以批准冻结、退回修改或取消未执行决策。批准时重新检查人员权限、日期、数量和预算。已提交记录即使退回也不能删除，事件保留。

## 实际履约

末次采购由指定采购员登记今日实际订单编号及供应商承诺交付日。系统不发送订单，登记应在真实订单已经签发且仍处于订购期限时进行，不能用历史日期绕过期限。订单金额和数量取冻结决策，不允许增加。分批登记收货凭证、数量、真实日期和核对依据；实际日期必须在订单日至今日之间，累计有效数量不得超批准数量。实际迟到仍允许忠实登记。台账不自动确认实物合格或供应商履约。

错误收货记录由指定独立复核员冲正，原行、原证据、冲正人时间和理由保留，数量回到待收货余量。冲正不代表退款或实物退货。更正后以新的唯一凭证编号登记，原编号不得重用。

替代和退役路线由指定采购执行员在组织实际完成相应工程变更或退役后登记实施凭证，不自动修改PLM或设备。

## 核验、关闭和导出

末次采购收齐后，或替代/退役有实际实施凭证后，指定复核员核对原始记录并关闭。关闭后不可更改、冲正或删除。导出保存范围内业务JSON，含通知、需求、计算、收货和事件，不附广告或密码。通知统计的金额是已批准末次采购申请额，不是银行付款额。

## 搜索和异常

通知支持编号、料号、制造商或名称搜索，状态筛选、最新/订购日/编号排序，每页20条。管理表支持本地搜索和分页。旧版本冲突时刷新详情核对后重新操作；连接未完成时保留窗口重试，相同UUID和载荷只记一次。不具备指定岗位、权限或数据范围时接口明确拒绝，菜单隐藏只是界面反馈。关于系统可查看许可与联系二维码。
